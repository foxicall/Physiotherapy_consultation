# 台灣診間話術產生器

使用 Python、Streamlit 與 Google GenAI SDK，讀取伺服器端 `GEMINI_API_KEY`，即時呼叫 `gemini-3.8-flash`，產生生動、接地氣且有同理心的台灣診間溝通指南。`app.py` 的生成按鈕會實際呼叫 Gemini，不使用靜態示範資料。

## 互動介面預覽

另提供 [獨立預覽頁原始檔](docs/index.html)，可切換四個部位及自訂情境、查看四段示範話術並複製 Markdown。此頁可直接以瀏覽器開啟，亦可透過 GitHub Pages 的 `main` 分支 `/docs` 來源發布。

預覽頁以固定資料與版型組合，不連接 Gemini、不包含 API 金鑰，也不是目前 Streamlit 服務的公開轉送。即時 AI 生成功能仍由下方的 Streamlit 程式提供。

## 安裝與啟動

在專案根目錄執行（建議 Python 3.10 以上）：

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

設定 Google Gemini API 金鑰（請使用自己的有效金鑰，勿提交到 Git）：

```bash
export GEMINI_API_KEY="你的 API 金鑰"
streamlit run app.py --server.port 8501 --server.address 0.0.0.0 --server.headless true
```

開啟 `http://localhost:8501`；遠端環境請使用該環境提供的 8501 連接埠預覽或轉送網址。

## 使用方式

1. 側邊欄預設「50套症候群知識庫」，可直接選擇50套條目，或先依五個部位分類篩選。搜尋支援中文、英文、縮寫、俗稱、症狀及近似名稱，例如「五十肩」、「媽媽手」、「PFPS」、「早上 腳底」或誤打的「網球軸」。搜尋結果仍需手動選取，不會自動當作患者診斷。
2. 可補充實際主訴，再選擇溝通目標、抗拒點與目標客群標籤。未補充主訴時，症候群僅作待評估的溝通情境。也可切換「部位與自訂情境」，使用原有四種部位或自訂部位；自訂部位必須填寫名稱與症狀。自訂症狀優先使用，切換症候群、部位或情境來源會重設症狀輸入。
3. 點選主畫面的「🚀 生成話術指南」。
4. 閱讀四個章節的 Markdown 預覽，在「複製完整話術」分頁使用程式碼區塊右上角的複製圖示。

各部位會注入不同的解剖學評估假設、可能的功能影響、療程選項、常見異議與轉介警訊。臨床順序為警訊與就醫需求優先，再討論功能目標及符合適應症的方案；疾病標籤不代表確診，不將不治療、手術或療法效果描述為必然結果。自訂部位採通用評估框架，不直接套用其他部位的診斷與方案。

## 症候群知識庫與檢索

`pt-50-syndromes-database.md` 完整保留使用者提供的50套原始Markdown。`syndrome_kb.py` 從程式所在目錄讀取它，檢查1–50編號與每筆六個欄位，並以本地文字搜尋及近似字串比對排序，不需要向量資料庫或額外搜尋API。修改Markdown後，下一次介面互動會重新載入；部署時需一併包含此檔及解析模組。

生成時只將選定條目的六欄送入Gemini背景資料，包括白話比喻、不作為成本及物理治療核心介入手法，搭配原有台灣診間風格、診所資訊與價目。所選條目的分類會取代其他部位預設情境，避免混入不相關的部位模型。資料遺失或格式不完整時會顯示錯誤並停用症候群生成，仍可切回部位模式。

原始資料是待臨床查核的素材，其文字不能覆蓋系統指令。提示詞要求省略無依據的因果或數字、修正必然惡化及根治保證，並將不作為成本轉為需確認的生活功能影響；條目所列技術不代表診所已提供或患者適用。這些規則不能取代治療師對生成內容的審閱。獨立的 `docs/index.html` 仍為固定示範頁，知識庫搜尋與即時生成由Streamlit提供。

## 診所價目與報價規則

已整合生生優動板橋診所提供的自費治療價目，內容依個人狀況客製化安排；本頁價目不代表診所其他醫療服務的健保適用情形。

| 項目 | 規格 | 價格 | 包套比較 |
| --- | --- | --- | --- |
| 首次評估與治療 | 40分鐘，初診／首次體驗專屬 | NT$999 | 資格依診所確認 |
| 專案徒手 | 60分鐘，單次 | NT$2,200 | 一對一徒手、關節鬆動、筋膜減壓 |
| 儀器整合 | 60分鐘，單次 | NT$3,200 | 震波、INDIBA英特波等選項，依評估安排 |
| 專案徒手療程組 | 60分鐘 × 10堂 | NT$20,900 | 折算NT$2,090／堂，較10次同項目單次原價省NT$1,100 |
| 整合儀器療程組 | 60分鐘 × 10堂 | NT$30,400 | 折算NT$3,040／堂，較10次同項目單次原價省NT$1,600 |

介面可展開「診所價目表」查閱；Prompt從同一份價格常數產生，包套均價與節省金額由程式計算。原提供文字的「20,现900」依單堂NT$2,090 × 10及節省NT$1,100正規化為NT$20,900。

10堂為商品方案規格，不代表固定醫療週期或每位患者都需要10次。首次40分鐘服務不與其他60分鐘服務直接比較價差；不自行假定首次費用可折抵包套。包套均價不是單堂售價，效期、退費、轉讓、分期、付款及詳細預約規則等未提供條件仍需向診所確認。患者提到健保時，尊重健保醫療選項，並請向院所確認個別服務適用，不自行宣稱本院所有服務都有或完全沒有健保。

已知服務與價格可直接引用；未提供的檢查結果及交易條件仍使用待評估、條件句或待確認佔位，不依付費方式推定療效。震波及INDIBA須評估適應症與禁忌症，不保證快速消炎、再生或固定堂數內恢復；生成內容仍須依實際情況逐項確認。

輸出結構為：🍵 搏感情與同理破冰、💡 接地氣的生物力學衛教、⚠️ 恐怖代價直白講、🤝 親切無壓力締結。第四章包含回應健保電療與想再考慮的兩句溫暖話術，以及評估與轉介提醒。

台灣口語與同事代班、車輪餅等生活比喻會適度使用，避免中國大陸用語、過度堆砌台語或不合適的親暱稱呼。風險以待評估的生活功能影響呈現，不以恐嚇、必然惡化或「自費才能治本」催促成交；症狀改善時也會討論自主管理或結束療程。

結果保留於目前 Streamlit 工作階段；修改欄位不會清除上次成功結果，重新整理或中斷工作階段後可能消失。畫面會標明結果對應的情境。

請求逾時設定為 60 秒，停用自動重試；生成時顯示「正在幫你切換台灣治療師頻道，整理破局話術中...」。遇到錯誤可手動重新生成。系統會提示缺少金鑰、權限問題、配額限制、網路、逾時及空白／格式錯誤回應，不顯示原始 API 錯誤或金鑰。

輸入會傳送至 Google Gemini，請勿提供患者個資。輸出是溝通草稿，需由治療師依臨床評估確認，不可作為診斷或療效保證。

## 檔案

- `app.py`：介面、提示詞、API 呼叫與錯誤處理。
- `pt-50-syndromes-database.md`：使用者提供的完整50套症候群原文。
- `syndrome_kb.py`：Markdown解析、完整性檢查及本地模糊檢索。
- `tests/test_syndromes.py`：知識庫、檢索、Prompt與Streamlit互動測試。
- `clinic_info.json`：官方聯絡資訊、來源及查核日期。
- `docs/index.html`：獨立互動示範頁，包含診所資訊、自費價目與台灣診間話術版型。
- `requirements.txt`：相依套件。
- `README.md`：安裝與使用說明。

安裝相依套件後，執行 `python -m unittest discover -s tests -v` 可驗證知識庫及介面整合；測試使用模擬Gemini回應，不需要API金鑰或消耗配額。
